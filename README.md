# GES Recruitment Portal — Demonstration

A static, browser-only recruitment application demonstration. Built with HTML, CSS and vanilla JavaScript. PDF generation uses jsPDF from a CDN.

## Run locally

Open `index.html` in a browser, or use VS Code Live Server.

## Deploy to Vercel

Import this folder/repository as a Vercel project. Framework preset: **Other**. Build command: leave blank. Output directory: `.`.

## Important

This is not an official Ghana Education Service portal. It does not transmit applications to GES or any government agency. Data is held in the browser for demonstration purposes. Do not enter real Ghana Card, SSNIT, or other sensitive personal information. Uploaded files are used locally for the PDF and are not uploaded to a server.
